# AI Classes - Образовательная платформа для инженерных классов

Backend API образовательной платформы на FastAPI с интеграцией AI для автоматической генерации тестов и адаптивного обучения.

## 🎯 О проекте

**AI Classes** — это веб-платформа для дистанционного обучения с AI-ассистентом, разработанная специально для инженерных классов. Система поддерживает три роли: студенты, преподаватели и администраторы.

### Ключевые возможности

- 📚 **Управление курсами**: создание курсов с модулями и материалами (видео, текст, PDF, презентации)
- 🤖 **AI-генерация тестов**: автоматическое создание тестов на основе материалов курса
- 📊 **Адаптивное тестирование**: система подсказок и блокировок при неудачных попытках
- 📈 **Отслеживание прогресса**: детальная аналитика успеваемости студентов
- 🔐 **Система заявок**: студенты подают заявки на курсы, преподаватели одобряют
- 🎓 **Последовательное обучение**: доступ к следующему материалу только после прохождения предыдущего

## 🏗️ Архитектура
- **models/**  SQLAlchemy ORM модели
- **schemas/**  Pydantic схемы для валидации
- **routers/**  API эндпоинты
- **service/**  Бизнес-логика
- **helpers/**  Вспомогательные функции
- **core/**  Конфигурация, безопасность
- **main.py**  Точка входа


## 🛠️ Технологический стек

- **Backend**: FastAPI (async)
- **База данных**: PostgreSQL + SQLAlchemy 2.0 (async)
- **Авторизация**: JWT 
- **Миграции**: Alembic
- **AI интеграция**: LiteLLM
- **Транскрипция**: Whisper / faster-whisper
- **Chunking**: Chonkie (semantic text splitting)
